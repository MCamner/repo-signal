# Skills

repo-signal ships local skills for maintaining static repository analysis,
symbolic intelligence exports, semantic memory, docs, terminal UX and release
readiness.

## Built-in skills

| Skill | Description |
| ----- | ----------- |
| [docs-maintainer](skills/docs-maintainer/SKILL.md) | Keep docs aligned with CLI, signal output and scoring behavior |
| [release-readiness](skills/release-readiness/SKILL.md) | Prepare and verify releases |
| [repo-aware](skills/repo-aware/SKILL.md) | Work repo-first with local structure and conventions |
| [repo-product-auditor](skills/repo-product-auditor/SKILL.md) | Review the repo as a product for clarity, discoverability and positioning |
| [semantic-memory-maintainer](skills/semantic-memory-maintainer/SKILL.md) | Maintain semantic memory packs, vector context and indexed markdown |
| [symbolic-intelligence-exporter](skills/symbolic-intelligence-exporter/SKILL.md) | Maintain symbol_index, callgraph, risk_map and mq-tool-facing exports |
| [terminal-ui-polisher](skills/terminal-ui-polisher/SKILL.md) | Polish terminal output, scoring tables and command-surface UX |
