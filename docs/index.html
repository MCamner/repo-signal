Publish Checklist CI Gate

repo-signal turns local repository state into clear release-readiness signals. Use --fail-under to fail a workflow when a repository drops below the required public quality score. 

repo-signal publish-checklist . --fail-under 14
repo-signal publish-checklist . --format json --fail-under 14

This makes repo quality measurable before release: README, docs, roadmap, screenshots, GitHub Pages readiness, issue templates, and safe-sharing signals.
